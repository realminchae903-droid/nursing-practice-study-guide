# nursing-practice-study-guide
간호학 실습 전 사전학습과 핵심 간호 개념을 정리하는 공개 학습자료 프로젝트
# Nursing Practice Study Guide

## 프로젝트 소개

이 프로젝트는 간호학 실습을 준비하는 학생들이 주요 질환, 간호중재, 검사, 약물, 환자 교육 내용을 쉽게 정리하고 복습할 수 있도록 만든 공개 학습자료입니다.

실습 전 사전학습을 할 때 필요한 내용을 주제별로 정리하여, 간호학생들이 핵심 개념을 빠르게 확인하고 실제 임상 상황과 연결해 이해할 수 있도록 돕는 것을 목표로 합니다.

## 프로젝트를 만든 이유

간호학 실습을 준비하면서 질환, 검사, 약물, 간호중재를 따로따로 정리해야 하는 경우가 많았습니다. 특히 신장내과, 중환자실, 소아청소년과, 정신간호학 실습처럼 학습 범위가 넓은 경우에는 핵심 내용을 체계적으로 정리할 필요가 있었습니다.

이 프로젝트는 이러한 학습 내용을 공개적으로 정리하여, 다른 간호학생들도 참고할 수 있는 자료로 발전시키기 위해 시작했습니다.

## 주요 내용

* 신장내과 실습 사전학습
* 혈액투석과 복막투석 비교
* 투석 환자 식이요법
* 고칼륨혈증 증상과 간호
* 중환자실 기본 장치 및 환자 관찰
* 간호진단과 간호중재 예시
* 실습 전 체크리스트

## 사용 방법

각 주제별 Markdown 파일을 열어 필요한 내용을 확인할 수 있습니다.

예시:

* `renal-dialysis.md` : 신장내과 및 투석 관련 내용
* `icu-basic-care.md` : 중환자실 기본 간호 내용
* `nursing-checklist.md` : 실습 전 확인할 체크리스트

## 앞으로의 개선 계획

* 실습 과목별 자료 추가
* 질환별 간호중재 정리
* 약물 정리표 추가
* 간호진단 예시 보완
* 학생들이 쉽게 볼 수 있도록 표와 체크리스트 형식 개선

## 유지관리 방향

이 프로젝트는 간호학 실습과 국가고시 준비 과정에서 필요한 내용을 지속적으로 추가하고 수정할 예정입니다. 잘못된 내용이나 보완이 필요한 부분은 수정하며, 실제 학습에 도움이 되는 자료로 발전시키는 것을 목표로 합니다.

## 주의사항

이 자료는 간호학 학습을 돕기 위한 참고자료이며, 실제 환자 진료나 의학적 판단을 대체하지 않습니다. 실제 임상에서는 의료기관 지침과 담당 의료진의 판단을 우선해야 합니다.
